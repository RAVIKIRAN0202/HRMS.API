# HRMS Backend API

A Human Resource Management System backend built using ASP.NET Core Web API, SQL Server, Entity Framework Core, JWT Authentication, and Role-Based Authorization.

## Features

- User Registration and Login
- JWT Authentication
- Role-Based Authorization: Admin, HR, Employee
- Department Management
- Designation Management
- Employee Management
- Leave Management
- Attendance Management
- Dashboard Summary API
- Swagger API Testing

## Tech Stack

- ASP.NET Core Web API
- C#
- Entity Framework Core
- Microsoft SQL Server
- JWT Authentication
- Swagger
- Git & GitHub

## Main Modules

### Authentication
- Register user
- Login user
- Generate JWT token

### Department
- Create department
- View departments
- Update department
- Delete department

### Designation
- Create designation
- View designations
- Update designation
- Delete designation

### Employee
- Create employee
- View employees
- Update employee
- Delete employee

### Leave Management
- Apply leave
- View leave requests
- Approve leave
- Reject leave

### Attendance
- Employee check-in
- Employee check-out
- View attendance

### Dashboard
- Total employees
- Total departments
- Total designations
- Pending leaves
- Approved leaves
- Rejected leaves
- Today attendance
